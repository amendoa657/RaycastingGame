# Jogo raycasting inspirado na tecnica de wolfenstein 3d

## No que consiste?
O jogo consiste numa tecnica chamada de raycasting, que utiliza traçado de linhas sobre um plano 2d para calcular profundidade, criando um cenario 3d, com calculos 2d

## Dependências
- [pygame]
- [python3]

## Como iniciar?
```sh
git clone https://github.com/amendoa657/RaycastingGame.git
cd RaycastingGame
python -m venv venv
pip install pygame
python Main.py
```
